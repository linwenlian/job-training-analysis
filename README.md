# 全职岗位「培训福利」现状与趋势分析（静态站点）

一个纯静态的分析看板：以招聘信息的 **岗位福利** 标签为切入点，回答两件事——

1. **有多少岗位把「培训」写进福利，这个比例随时间怎么变？**
2. **提供培训的岗位有哪些特征？**（职位、城市、行业、薪资、学历、经验、企业规模、技能标签、岗位描述）

线上地址：<https://linwenlian.github.io/job-training-analysis/>

## 数据合规

- 本仓库与线上页面**只包含聚合统计量**：维度合计、比例、薪资中位数等。
- **不包含**原始岗位记录、企业名称、岗位描述原文，或任何可回溯到单条招聘信息的内容。
- 比率类指标设置最小样本量门槛（默认 30 条，列表类维度 100 条），样本不足的组合不展示。
- 脚本 `analysis/` 中只有统计口径与映射表（职位大类归并、关键词表），不含任何数据。

## 站点结构

```
index.html          页面结构（单页，含导航）
assets/style.css    样式
assets/app.js       全部图表逻辑（原生 JS + 内联 SVG，无第三方依赖）
data/stats.js       预先算好的聚合统计量（由 analysis/build_data.py 生成）
analysis/           聚合统计脚本（离线运行，需要原始数据）
```

页面不请求任何外部 CDN 或接口，加载后可离线浏览；所有图表由 `data/stats.js` 中的聚合量渲染。

## 统计口径摘要

- **培训岗位**：岗位福利标签中出现「培训」字样的岗位（如 `带薪培训`、`免费培训`、`专业培训`、`组织培训`、`教育培训`、`免费培训上岗` 等）。
  广义口径（`带教`/`师带徒`/`学徒`/`培养`/`进修`）单独统计，仅作参考。
- **薪资**：取薪资区间中位数（`5000-8000元` 记 6500 元）；`面议` 与时薪岗位不计入薪资统计，13 薪不折算。
- **职位大类**：将百余个原始职业类别归并为 17 个大类（财务/金融/法务、销售/营销、研发/技术、生产制造、互联网运营、客服、零售/餐饮/生活服务等）。
- **城市等级**：一线 / 新一线 / 二线 / 其他城市。
- **行业**：原始字段为多值，一条岗位可计入多个行业。
- **岗位描述关键词**：对描述正文做规则匹配，共 30+ 组关键词，并按「软技能与任职要求 / 专业与硬技能信息 / 工作条件与福利话术」三类分别呈现。
  第三类（提成奖金、双休、晋升成长等）之所以出现在描述里，是因为招聘方常把福利待遇一并写进正文，不应作为任职要求解读。
- **技能类型**：把技能标签按关键词规则归为 20 类。注意该字段本身混有行业/领域类标签（如「互联网」「企业服务」）与福利类标签（如「五险一金」「包住」），页面在每类旁给出高频示例标签便于核对。

## 页面结论要点（含两个专项问题）

- 「学习能力」等软技能：培训岗位的岗位描述中提到学习能力的比例高于非培训岗位（11.99% vs 9.28%），服务意识（22.4% vs 11.3%）、形象/年龄等条件提及、吃苦耐劳、积极主动、稳定性的差距更大；而逻辑与解决问题、团队协作、执行力、组织管理能力等反而更低。
- 专业口径：培训岗位更常写「专业不限 / 不限专业」（4.30% vs 2.16%，约 2 倍），同时更少要求「相关 / 对口专业」（14.63% vs 31.08%）与特定专业背景（25.62% vs 39.51%），即更偏向「专业门槛宽松、靠培训补足技能」。
- 技能类型联动：与培训最同向的是教育/培训能力、服务类、销售/客户开发类技能；最反向的是财务/税务/审计、机械/电气/自动化、软件工程等专业硬技能。
- 结构画像支持按培训率排序看「前 20 / 后 20」，并可把样本量门槛切换到 500 / 1000。

## 方法与已知局限

- 全部为描述性统计，**不做因果推断**；页面未做结构分解或回归控制。
- 福利标签的**填写完整度差异极大**：标注培训的岗位全部填写了福利标签（平均 6.62 个），未标注培训的岗位有 57.1% 福利标签为空（平均 1.89 个）。
  因此「培训岗位其它福利看起来更全」有相当部分来自填写完整度，页面为此专门给出「非培训岗位中已填写福利标签者」的对照口径。
- 「教育培训」行业本身培训标注率很高（属行业自指），在职位大类对比中已单独说明。
- 小样本维度（如「无经验」「初中及以下」）的比率波动更大，请结合页面上标注的样本量解读。

## 复现方式（离线，需自备原始数据）

```bash
python analysis/analyze.py          # 单次流式扫描，输出 out/stats.json（聚合统计）
python analysis/benefit_count.py    # 福利标签填写密度控制项，输出 out/benefit_density.json
python analysis/build_data.py       # 合并为站点数据 data/stats.js
```

原始 CSV 需放置在 `raw/fulltime_jobs_202601_202609.csv`，字段包含：发布时间、职业类别、工作城市、薪资水平、岗位福利、学历要求、经验要求、技能标签、岗位描述、公司规模、公司行业。
